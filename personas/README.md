# 双 AI 人格模板

`大肥鱼.template.md` 与 `大肥龙.template.md` 保留当前角色性格、朋友关系、看图习惯和工具使用约定。这里不包含真实账号、群号、登录凭据或聊天历史。

使用前复制模板，替换全部占位符：

| 占位符 | 本地填写的值 |
| --- | --- |
| `{{OWNER_QQ}}` | AI 项目管理员 / 主人的 QQ |
| `{{FISH_QQ}}` | 大肥鱼的 QQ |
| `{{DRAGON_QQ}}` | 大肥龙的 QQ |
| `{{GROUP_QQ}}` | 共同测试群 QQ 群号 |

在各机器人控制台的人格页粘贴替换后的内容并选择该人格。也可以把本地成品放在 `personas/local/`（Git 已忽略）。人格注入上限应至少为 9000 字符，保存后检查控制台注入预览完整；不能把未替换的占位符直接投入群聊。

AI 项目管理员不等于 QQ 群主，模板中“大肥鱼的主人在该群不是群主”须按部署的实际身份核对。昵称只用于称呼，身份和真实 @ 使用平台 QQ 字段。

模板中的工具说明对应本项目后端：大肥鱼使用 DSH MCP 前缀，大肥龙使用 Codex 动态工具别名。上线前在控制台核对该实例已启用工具；人格不能自行授予工具权限。

角色示例是虚构提示词，不是导出的聊天记录。当前部署中的账号绑定、人设和运行状态不会因发布模板而被覆盖。
